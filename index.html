DI Player

Nativní GNOME přehrávač prémiového rádia DI.fm

Instalace

Nainstalovat DI Player

Otevře se v aplikaci Software. Nebo v terminálu:

flatpak install --user https://imbecile6197.github.io/di-player/di-player.flatpakref

Aktualizace pak instaluje aplikace Software nebo příkaz flatpak update.

Je-li to vaše první aplikace z Flatpaku a DI Player se v přehledu aplikací neobjeví, odhlaste se a znovu přihlaste.

Installation

Click the button above to install with Software, or run the command in a terminal. Updates are installed by Software or by flatpak update. If it is your first Flatpak app and DI Player does not appear in the app overview, log out and back in once.

Starší balíčky RPM/DEB (repozitáře rpm/ a deb/) se už neaktualizují – přejděte prosím na flatpak.
